# Overview of ODE code

- Flow_Fit_ODE3_multi.m runs the model multiple times, performing parameter sweep in parameter "a" (film thickness).
- Flow_Fit_ODE3_plot_Rsol.m plots time series data from Flow_Fit_ODE3_multi.m code.
- Flow_Fit_ODE3_plot_plugRate.m plots the plugging rate from  Flow_Fit_ODE3_multi.m code.
- Rb_Rc_fitting_main.m and Rb_Rc_fitting_func.m finds Rb and Rc value at each "a" from the PDE function.
